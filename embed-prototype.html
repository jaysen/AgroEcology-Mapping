Mapping Agroecology Initiatives in South Africa

In 2025 and early 2026 the Agroecology Action Collective, which advocates across South Africa to create spaces of power and joint action to transform the food system, conducted a survey of agroecology initiatives in South Africa. The objective was to identify, gather information about, and map promising agroecology initiatives in South Africa in order to inform network-building strategies, to identify initiatives for possible learning exchanges, for new entrants to agroecology to know where to go to get support, and to promote and communicate about agroecology in farmer and wider civil society networks, amongst decision-makers, and with the general public.

This first phase of the mapping is a pilot, to test methodologies and get an initial view of initiatives in the immediate networks of the Agroecology Action Collective. As such, it is not a comprehensive map of all initiatives in the country, with cases mainly clustered in areas of KwaZulu-Natal and Eastern Cape.

For developers

The prototype above shows how the map will appear on the Agroecology Action Collective website. Use the snippets below to embed the live map on any page — no build step required, just copy and paste.

Option 1 — Responsive iframe (recommended)

Wraps the iframe in a container that maintains a 16:9 aspect ratio and scales with the page width. Works in plain HTML and most page builders (WordPress, Squarespace, Webflow, etc.). 

<!-- Agroecology Map embed -->
<div style="
  width: 100%;
  aspect-ratio: 16 / 9;
  min-height: 400px;
  border-radius: 4px;
  overflow: hidden;
  border: 1px solid #ccc;
">
  <iframe
    src="https://jaysen.github.io/AgroEcology-Mapping/"
    title="Agroecology Action Collective Projects Map"
    style="width: 100%; height: 100%; border: none; display: block;"
    loading="lazy"
    allow="fullscreen"
  ></iframe>
</div>

Option 2 — Fixed height iframe

Simpler option with a fixed pixel height. Useful when the container width is already constrained (e.g. a sidebar or fixed-layout template). 

<!-- Agroecology Map embed — fixed height -->
<iframe
  src="https://agroecologyaction.org.za/map/"
  title="Agroecology Action Collective Projects Map"
  width="100%"
  height="560"
  style="border: none; border-radius: 4px; display: block;"
  loading="lazy"
  allow="fullscreen"
></iframe>
Adjust height to suit your layout. 500–600 px works well for most desktop widths; 400 px is a reasonable minimum for mobile.

WordPress — Custom HTML block

In the WordPress block editor (Gutenberg), insert a Custom HTML block and paste either snippet above. No plugin required. 

1. Open the page/post in the WordPress editor.
2. Click the ⊕ button to add a new block.
3. Search for "Custom HTML" and select it.
4. Paste the embed code (Option 1 or Option 2) into the block.
5. Preview and publish.
If your WordPress theme enforces a maximum content width, set the block to "Full width" or "Wide" alignment using the block toolbar to give the map enough horizontal space.
