Agroecology Map – Embed Examples

Three ways to embed the interactive map on any website

1

Responsive iframe

The iframe is wrapped in a container that maintains a 16:9 aspect ratio and scales with the page width. Recommended for most use cases — works in plain HTML pages and all major page builders (WordPress, Squarespace, Webflow, etc.).

Live preview
Embed code
<div style="
  width: 100%;
  aspect-ratio: 16 / 9;
  min-height: 400px;
  border-radius: 6px;
  overflow: hidden;
  border: 1px solid #ccc;
">
  <iframe
    src="https://jaysen.github.io/AgroEcology-Mapping/"
    title="Agroecology Action Collective Projects Map"
    style="width: 100%; height: 100%; border: none; display: block;"
    loading="lazy"
    allow="fullscreen"
  ></iframe>
</div>
2

Fixed height iframe

A simpler embed with a fixed pixel height. Useful when the container width is already constrained (e.g. a sidebar or fixed-layout template) or when you need precise control over the map's dimensions.

Live preview
Embed code
<iframe
  src="https://jaysen.github.io/AgroEcology-Mapping/"
  title="Agroecology Action Collective Projects Map"
  width="100%"
  height="500"
  style="border: none; border-radius: 6px; display: block;"
  loading="lazy"
  allow="fullscreen"
></iframe>
Adjust height to suit your layout. 480–600 px works well for most desktop widths; 400 px is a reasonable minimum for mobile.
4

Responsive iframe with fullscreen button

Same responsive wrapper as Option 1, with a fullscreen button overlaid in the top-right corner. Clicking it expands the map to fill the browser window. Uses the browser's native Fullscreen API — no plugins or dependencies required.

Live preview — click the button to go fullscreen
Embed code
<div id="mapWrap" style="
  position: relative;
  width: 100%;
  aspect-ratio: 16 / 9;
  min-height: 400px;
  border-radius: 6px;
  overflow: hidden;
  border: 1px solid #ccc;
">
  <button
    onclick="toggleFullscreen(document.getElementById('mapWrap'))"
    style="
      position: absolute; top: 10px; right: 10px; z-index: 1000;
      background: white; border: 1px solid #ccc; border-radius: 5px;
      padding: 5px 10px; cursor: pointer; font-size: 0.8rem; font-weight: 600;
      box-shadow: 0 1px 4px rgba(0,0,0,0.15);
    "
  >&#x26F6; Fullscreen</button>
  <iframe
    src="https://agroecologyaction.org.za/map/"
    title="Agroecology Action Collective Projects Map"
    style="width: 100%; height: 100%; border: none; display: block;"
    loading="lazy"
    allow="fullscreen"
  ></iframe>
</div>

<script>
function toggleFullscreen(el) {
  if (!document.fullscreenElement) {
    el.requestFullscreen();
  } else {
    document.exitFullscreen();
  }
}
</script>
The ⛶ character (⛶) is a Unicode fullscreen icon — replace it with any text or SVG icon you prefer. The button disappears automatically when the browser UI provides its own fullscreen controls.
3

WordPress – Custom HTML block

In the WordPress block editor (Gutenberg), insert a Custom HTML block and paste either snippet above. No plugin required.

In the WordPress editor it looks like this
Custom HTML block Paste Option 1 or Option 2 code here — the map renders on the published page.
Steps
1. Open the page or post in the WordPress editor.
2. Click ⊕ to add a new block — search for "Custom HTML".
3. Paste the Option 1 or Option 2 code into the block.
4. Click Preview to check the result, then Publish.
If your theme enforces a maximum content width, set the Custom HTML block alignment to Wide or Full width using the block toolbar — this gives the map enough horizontal space to be usable.
