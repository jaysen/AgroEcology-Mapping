# AgroEcology Maps

Interactive map for displaying agroecology case studies across Southern Africa. Built with TypeScript, Vite, Leaflet.js, and OpenStreetMap.

**📖 Full project details:** See [docs/ProjectSpec.md](docs/ProjectSpec.md)

## Quick Start

```bash
npm install
npm run dev      # Dev server at http://localhost:5173
npm run build    # Production build
```

## Deploy

| Target                | Command           |
|-----------------------|-------------------|
| Local / hand-off dist | `npm run build`   |
| GitHub Pages          | `npm run deploy`  |

See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for full instructions.
